# Event Management App

A cross-platform event management application built with Flutter and Firebase. This app allows organizers to create and manage events, zones, tracks, sessions, stalls, and tickets. Users can browse, register, and participate in events.

## Features

- Organizer and User dashboards
- Event creation and configuration
- Zone, Track, Session, and Stall management
- Ticket types, sales, and validation
- Firebase Firestore integration
- Authentication (Firebase Auth)
- Real-time updates
- Responsive UI for mobile and web



## Getting Started

### Prerequisites
- Flutter SDK (latest stable)
- Dart SDK
- Firebase project (Firestore, Auth enabled)
- Android Studio / Xcode / VS Code

### Setup
1. Clone the repository:
   ```sh
git clone <repo-url>
cd event_management_app1
   ```
2. Install dependencies:
   ```sh
flutter pub get
   ```
3. Add your Firebase config files:
   - `android/app/google-services.json`
   - `ios/Runner/GoogleService-Info.plist`
4. Run the app:
   ```sh
flutter run
   ```
